호수 밑바닥에서 그림자 하나가 다시 울립니다. 그림자 메아리도 같은 규칙으로 갈라집니다. 세기 0인 메아리는 한 번 울리고, 세기 n(n ≥ 1)인 외침은 세기 `n // 2`와 `n // 3`인 두 메아리로 갈라집니다. 즉 E(0) = 1, E(n) = E(n // 2) + E(n // 3)입니다. 질문마다 E(n)을 출력하세요.

**입력**: 첫째 줄에 Q(1 ≤ Q ≤ 20), 다음 Q줄에 세기 n이 하나씩(0 ≤ n ≤ 10,000).

**출력**: 질문마다 한 줄에 E(n).

**예제**

| 입력 | 출력 |
|---|---|
| `3`<br>`2`<br>`5`<br>`0` | `3`<br>`5`<br>`1` |
