그림자 호수에 돌을 던지면 물결이 갈라집니다. 세기 0인 물결은 한 번 출렁이고 사라지고, 세기 n(n ≥ 1)인 물결은 세기 `n // 2`와 `n // 3`인 두 물결로 갈라집니다. 세기 n의 물결이 모두 몇 번 출렁이는지 E(n)을 구하세요. E(0) = 1, E(n) = E(n // 2) + E(n // 3)입니다.

**입력**: 첫째 줄에 Q(1 ≤ Q ≤ 20), 다음 Q줄에 세기 n이 하나씩(0 ≤ n ≤ 10,000).

**출력**: 질문마다 한 줄에 E(n).

**예제**

| 입력 | 출력 |
|---|---|
| `3`<br>`12`<br>`0`<br>`30` | `12`<br>`1`<br>`21` |
