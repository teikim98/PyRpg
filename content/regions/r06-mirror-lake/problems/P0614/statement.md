호수 한가운데 섬에 이르자, 동심원 물결이 겹겹이 겹친 거대한 정령이 수면 위로 떠오릅니다. 가슴에는 빼앗긴 호수의 시계 룬이 박혀 있습니다. **호수의 메아리**입니다. 메아리는 대정지 뒤로 끝없이 갈라지며 되돌아와, 정령이 묻는 질문에 답해야만 흩어집니다.

이 호수에서 세기 n의 외침은 이렇게 울립니다.

- 세기 **0**인 메아리는 더 갈라지지 않고 **한 번** 울립니다.
- 세기 n(n ≥ 1)인 외침은 세기 `n // 2`인 메아리와 세기 `n // 3`인 메아리 둘로 갈라져 돌아옵니다. 갈라진 메아리도 같은 규칙으로 다시 갈라집니다.

세기 n의 외침이 결국 몇 번 울리는지를 E(n)이라고 하면, E(0) = 1이고 n ≥ 1이면 E(n) = E(n // 2) + E(n // 3)입니다. 예를 들어 세기 1은 세기 0과 0으로 갈라져 E(1) = 2번, 세기 6은 세기 3과 2로 갈라져 E(6) = E(3) + E(2) = 4 + 3 = 7번 울립니다.

질문 Q개가 주어집니다. 질문마다 E(n)을 출력하세요.

**입력**: 첫째 줄에 질문의 수 Q가 주어집니다. (1 ≤ Q ≤ 100) 다음 Q줄에 외침의 세기 n이 하나씩 주어집니다. (0 ≤ n ≤ 1,000,000,000,000,000,000)

**출력**: 질문마다 한 줄에 E(n)을 출력합니다.

**예제**

| 입력 | 출력 |
|---|---|
| `4`<br>`0`<br>`1`<br>`6`<br>`10` | `1`<br>`2`<br>`7`<br>`9` |

> 1페이즈에서는 n이 10,000 이하이고 Q가 20 이하입니다. 1페이즈를 통과하면 메아리가 '시간 결계'를 펼치고 2페이즈가 시작됩니다. 2페이즈에서는 n이 10^15 ~ 10^18로 커지고 시간 제한이 걸립니다.
