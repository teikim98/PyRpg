고리 길 가장자리에 숫자 무늬 버섯이 돋아 있습니다. 버섯은 수 N에서 시작해 **D씩 줄여 가며 0 이상인 수만** 거꾸로 세는 주문을 들어야 포자를 거둡니다.

**입력**: 첫째 줄에 두 정수 N, D가 공백 하나를 사이에 두고 주어집니다. (0 ≤ N ≤ 1000, 1 ≤ D ≤ 1000)

**출력**: N, N - D, N - 2D, …를 0 이상인 동안 차례로, 한 줄에 공백 하나씩 사이에 두고 출력합니다.

**예제**

| 입력 | 출력 |
|---|---|
| `10 3` | `10 7 4 1` |

> 줄 끝의 공백은 채점할 때 무시되니까 걱정하지 마세요.
