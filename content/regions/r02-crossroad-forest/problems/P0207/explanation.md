몇 번 돌지 미리 모를 때는 `while`이야. **n이 1이 아닌 동안** 규칙을 적용하고 횟수를 세면 돼.

- `while 조건:`은 조건이 참인 동안 블록을 되풀이해. 처음부터 거짓이면 한 번도 안 돌아서, n = 1이면 바로 0을 돌려줘.
- 짝수면 `n = n // 2`, 홀수면 `n = n * 3 + 1`. **`n =`으로 다시 넣어야** n이 바뀌어. `n * 3 + 1`만 쓰면 계산 결과를 버리는 거라서 n이 그대로고, 조건 `n != 1`이 영원히 참이야. 이게 무한루프, 숲의 시간 결계가 노리는 함정이야.
- `while`을 쓸 때마다 스스로 물어봐: "조건에 쓰인 변수가 반복마다 끝을 향해 바뀌고 있나?"
- `/`로 나누면 `3.0`처럼 실수가 돼. 이 문제의 범위에선 횟수는 맞지만, 큰 수에서는 정밀도를 잃을 수 있으니 정수 나눗셈 `//`를 쓰는 습관을 들이자.
- `answer += 1`은 `answer = answer + 1`의 줄임말이야. JS의 `answer++`는 Python에 없어(`SyntaxError`).
- 참고: 이 규칙을 따르면 모든 양의 정수가 결국 1이 된다는 '콜라츠 추측'은 아직 아무도 증명하지 못했어. 100만까지는 컴퓨터로 확인이 끝나 있어서 안심하고 돌려도 돼.
