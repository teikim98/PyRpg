고리 길에 들어서자 자기 꼬리를 문 뱀이 길을 막습니다. 뱀은 수 N을 외치고, 메아리처럼 **N단 곱셈을 1부터 K까지** 차례로 되돌려 주면 고리를 풀어 준다고 합니다.

**입력**: 첫째 줄에 두 정수 N, K가 공백 하나를 사이에 두고 주어집니다. (1 ≤ N ≤ 100, 1 ≤ K ≤ 30)

**출력**: K줄에 걸쳐, i번째 줄에 `N x i = (N × i의 값)`을 출력합니다. `x`는 영어 소문자 x이고, 기호 양옆에 공백이 한 칸씩 있습니다.

**예제**

| 입력 | 출력 |
|---|---|
| `3 4` | `3 x 1 = 3`<br>`3 x 2 = 6`<br>`3 x 3 = 9`<br>`3 x 4 = 12` |
