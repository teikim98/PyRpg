덩굴 뱀이 길을 감고 있습니다. 뱀이 외친 수 N의 **곱셈을 1부터 K까지** 메아리처럼 되돌려 주면 덩굴이 풀립니다.

**입력**: 첫째 줄에 두 정수 N, K가 공백 하나를 사이에 두고 주어집니다. (1 ≤ N ≤ 100, 1 ≤ K ≤ 30)

**출력**: K줄에 걸쳐, i번째 줄에 `N x i = (N × i의 값)`을 출력합니다. `x`는 영어 소문자 x이고, 기호 양옆에 공백이 한 칸씩 있습니다.

**예제**

| 입력 | 출력 |
|---|---|
| `2 5` | `2 x 1 = 2`<br>`2 x 2 = 4`<br>`2 x 3 = 6`<br>`2 x 4 = 8`<br>`2 x 5 = 10` |
