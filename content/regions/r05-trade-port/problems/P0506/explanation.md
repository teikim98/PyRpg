지나간 번호를 **집합**에 기억해 두고, 새 번호가 이미 집합에 있는지 보면 돼.

- `seen = set()`으로 빈 집합을 만들어. `seen = {}`는 빈 **dict**라서 `seen.add(x)`에서 `AttributeError: 'dict' object has no attribute 'add'`가 나.
- `if x in seen: return x`: 이미 본 번호면 그게 '다시 나온 첫 번호'야. 아니면 `seen.add(x)`로 기억해.
- 반복문이 끝까지 돌았다면 같은 번호가 없었던 거니까 `return -1`. 이 줄을 빠뜨리면 함수가 `None`을 돌려줘.
- `cargo.count(x) > 1`인 첫 `x`를 고르면 '두 번 나오는 번호 중 **처음 나온** 것'이 돼서 답이 달라져. `[5, 3, 3, 5]`라면 다시 나온 첫 번호는 `3`인데 `count`로 고르면 `5`야. 게다가 `count`는 매번 리스트 전체를 세니까 느려.
- 리스트 `seen = []`에 모아도 답은 맞지만, `x in 리스트`는 앞에서부터 하나씩 비교해. 집합의 `in`은 크기와 상관없이 바로 알려 줘.
