hp ÷ atk를 **올림**한 값이 답이야.

- 나누기 전에 `atk - 1`을 더하면, 나누어떨어지지 않을 때만 몫이 1 늘어나. 예를 들어 `(10 + 2) // 3`은 `4`, `(9 + 2) // 3`은 `3`이야.
- `-(-hp // atk)`도 같은 결과를 내. `//`는 음수 쪽으로 내림하니까, 부호를 두 번 뒤집으면 올림이 돼.
- 둘 다 정수 연산만 쓰므로 큰 수에서도 정확해. `math.ceil(hp / atk)`는 `/`에서 실수를 거치기 때문에 10^18 근처에서 틀려.
- JS라면 `Math.ceil(hp / atk)`를 썼겠지만, JS는 애초에 10^18을 정확히 담지 못해. Python에서는 정수 연산으로 올림하는 습관을 들이자.
