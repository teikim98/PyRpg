큰 단위부터 몫으로 떼어 내고, 남은 것은 나머지로 넘기는 게 요령이야.

- 시: 1시간은 3600초니까 `sec // 3600`.
- 분: 시로 떼어 내고 남은 초는 `sec % 3600`이야. 여기서 60으로 나눈 몫이 분이니까 `sec % 3600 // 60`. `sec // 60 % 60`(전체 분을 60으로 나눈 나머지)도 같은 값이야.
- 초: 분으로 떼어 내고 남은 것이니까 `sec % 60`.
- `sec // 60`만 쓰면 이미 시로 넘어간 분까지 세어서 `3661`초가 `61`분이 돼.
- `int(sec / 3600)`은 작은 수에서는 맞지만, `/`가 실수를 거치면서 큰 수의 끝자리가 뭉개져. `999999999999997199`초는 3600으로 나누어떨어지기 1초 전인데, 실수로 계산하면 반올림되어 시가 1 커져.
- 연산자 우선순위: `%`와 `//`는 같은 순위라서 왼쪽부터 계산해. `sec % 3600 // 60`은 `(sec % 3600) // 60`이야.
