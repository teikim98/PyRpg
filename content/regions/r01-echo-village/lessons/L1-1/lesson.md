# 목소리의 주문: `print`와 `input`

좋아, 첫 주문이야! 코딩테스트 문제는 결국 **입력을 듣고, 답을 말하는 것**이야. 그래서 말하는 주문 `print`와 듣는 주문 `input`이 모든 주문의 시작이지.

## `print`: 말하기

`print(...)` 괄호 안에 넣은 값을 화면에 출력해. 값을 쉼표로 여러 개 넣으면 사이에 **공백 한 칸**을 끼워서 한 줄에 말해 줘. 아래 [실행]을 눌러 봐!

```python run
print("안녕, 에코 마을!")
print(1, 2, 3)
print("금화", 30, "개")
```

```js compare
console.log("안녕, 에코 마을!");
console.log(1, 2, 3);        // 1 2 3  ← 여기까진 똑같아!
console.log("금화", 30, "개");
```

## `sep`과 `end`: 사이와 끝 바꾸기

`print`는 값 **사이**에 `sep`(기본값: 공백)을, 출력 **끝**에 `end`(기본값: 줄바꿈 `"\n"`)를 붙여. 둘 다 바꿀 수 있어.

```python run
print(2026, 10, 1, sep="-")
print("메아리", end="~")
print("메아리", end="~")
print("끝!")
```

- `sep="-"` → 값 사이에 공백 대신 `-`
- `end="~"` → 줄을 바꾸는 대신 `~`를 붙이고, 다음 `print`가 **같은 줄**에 이어서 찍혀

```js compare
// console.log는 사이 문자나 끝 문자를 못 바꿔서 이렇게 돌아가야 했지
console.log([2026, 10, 1].join("-"));
process.stdout.write("메아리~");   // Node에서 줄바꿈 없이 출력
```

## 변수: 이름표 붙이기

`=`로 값에 이름을 붙이면 그게 변수야. JS의 `let`, `const` 같은 말은 필요 없어. 그냥 이름 쓰고 `=`!

```python run
gold = 30
name = "누리"
print(name, "의 금화:", gold, sep="")
```

```js compare
let gold = 30;          // Python은 let/const 없이 gold = 30
const name = "누리";
```

## `input`: 듣기

`input()`은 입력을 **한 줄** 읽어서 돌려줘. 전투에서는 문제의 입력이 여기로 들어와.

```python
name = input()       # 입력 한 줄을 읽어서 name에 담아
print("안녕,", name)
```

여기서 아주 중요한 것 하나! `input()`이 돌려주는 값은 **언제나 문자열**이야. `3`을 입력해도 숫자 `3`이 아니라 글자 `"3"`이 와. 숫자로 바꾸는 법은 다음 비석에서 배울 거야.

```js compare
const name = prompt("이름?");   // prompt도 언제나 문자열(또는 null)을 돌려주지
// Python의 input()도 마찬가지로 언제나 문자열!
```

> 꿀팁: `input("이름? ")`처럼 괄호 안에 안내 문구를 넣을 수도 있어. 그런데 코딩테스트에서는 그 문구까지 출력으로 채점돼서 오답이 돼. 괄호는 비워 두자!
