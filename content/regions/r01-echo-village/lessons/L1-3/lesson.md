# 산술의 주문: 몫과 나머지, 그리고 아주 큰 수

상점 거리에선 금화를 나누고, 남는 걸 세고, 큰 수를 다룰 일이 많아. 산술 연산자 일곱 개를 한 번에 정리하자!

## 연산자 일곱 개

```python run
print(7 + 2, 7 - 2, 7 * 2)
print(7 / 2)     # 나누기: 언제나 실수(float)
print(7 // 2)    # 몫: 소수점 아래를 버린 정수
print(7 % 2)     # 나머지
print(2 ** 10)   # 거듭제곱
print(10 / 10)   # 나누어떨어져도 1.0!
```

| 연산자 | 뜻 | `7 ? 2` |
|---|---|---|
| `/` | 나누기(결과는 언제나 실수) | `3.5` |
| `//` | 몫 | `3` |
| `%` | 나머지 | `1` |
| `**` | 거듭제곱 | `49` |

```js compare
Math.floor(7 / 2);   // 3   ← Python에선 7 // 2 한 방
7 % 2;               // 1   ← 같아
2 ** 10;             // 1024 ← 같아
10 / 10;             // 1   ← Python은 1.0 (실수)
```

> `//`는 '내림'이야. 음수에서는 `-7 // 2`가 `-4`가 돼. JS의 `Math.floor(-7 / 2)`와 같아.

## Python의 `int`는 끝이 없어

JS의 `Number`는 2^53(약 9천조)을 넘으면 정수를 정확히 담지 못해. Python의 `int`는 **크기 제한이 없어.** 코딩테스트에 10^18 같은 큰 수가 나와도 걱정 없어!

```python run
print(2 ** 100)
print(1000000000000000000 + 1)
```

```js compare
2 ** 53 + 1;               // 9007199254740992  ← 1이 사라졌어!
1000000000000000000 + 1;   // 1000000000000000000 ← 또 사라짐
```

## 함정: `/`를 거치면 큰 수가 뭉개져

정수는 끝이 없지만 **실수(float)는 16자리쯤에서 끝자리가 뭉개져.** `/`는 결과가 실수니까, 큰 수의 몫은 꼭 `//`로 구해!

```python run
big = 1000000000000000000
print(int(big / 3))   # 333333333333333312  ← 틀림!
print(big // 3)       # 333333333333333333  ← 정확
```

## 또 하나의 함정: 4300자리

계산은 얼마든지 되지만, **4300자리가 넘는 정수를 문자열로 바꾸는 것**(출력 포함)은 Python이 기본으로 막아 둬.

```python
print(10 ** 5000)
# ValueError: Exceeds the limit (4300 digits) for integer string conversion
```

이럴 땐 맨 위에서 제한을 풀어 주면 돼. `0`은 '제한 없음'이야.

```python run
import sys
sys.set_int_max_str_digits(0)
print(len(str(10 ** 5000)))
```
