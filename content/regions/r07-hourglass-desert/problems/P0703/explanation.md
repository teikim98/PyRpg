반복을 직접 돌리지 말고, 몇 번 도는지를 **`n`의 식으로 세는** 문제야.

- `i = 0`이면 안쪽 반복이 `n - 1`번, `i = 1`이면 `n - 2`번, …, 마지막 `i = n - 1`이면 0번이야. 다 더하면 `(n - 1) + (n - 2) + … + 1 + 0`.
- 1부터 `m`까지의 합은 `m * (m + 1) // 2`니까, `m = n - 1`을 넣으면 `n * (n - 1) // 2`. '서로 다른 두 개를 고르는 방법 수'와 같아.
- 반복을 그대로 돌리면 실행 횟수가 약 `n² / 2`번이야. `n = 10억`이면 5억 × 10억 번이라, 1초에 대략 천만 번 안팎을 하는 Python으로는 끝나지 않아. 이런 걸 O(N²)이라고 하고, 식 하나로 끝내면 O(1)이야.
- `/`로 나누면 결과가 실수(`float`)가 돼. 실수는 큰 수를 정확히 담지 못해서 끝자리가 틀어져. 정수 나눗셈 `//`를 쓰자. `n * (n - 1)`은 늘 짝수라 `// 2`로 딱 나누어떨어져.
- 안쪽 반복이 `i + 1`부터라서 `i`와 `j`가 같은 경우는 세지 않아. `n * (n + 1) // 2`는 같은 경우까지 센 값이야.
