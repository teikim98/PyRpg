모래 그림자 속에서 문지기 하나가 다시 명부를 펼칩니다. 명부에 적힌 이름 N개와 문을 지나가려는 사람 Q명의 이름이 주어집니다. 지나가려는 사람마다 명부에 이름이 있으면 `1`, 없으면 `0`을 한 줄에 하나씩 출력하세요. 이름은 대소문자를 구분하고(`Pip`과 `pip`은 다른 사람), 명부에 같은 이름이 여러 번 있거나 같은 사람이 여러 번 올 수 있습니다.

**입력**: 첫째 줄에 N(1 ≤ N ≤ 1,000), 다음 N줄에 명부의 이름, 그다음 줄에 Q(1 ≤ Q ≤ 1,000), 다음 Q줄에 지나가려는 사람의 이름이 하나씩(영어 대·소문자 1~10글자).

**출력**: 지나가려는 사람마다 한 줄에 `1` 또는 `0`.

**예제**

| 입력 | 출력 |
|---|---|
| `3`<br>`lune`<br>`Pip`<br>`oda`<br>`3`<br>`oda`<br>`pip`<br>`lune` | `1`<br>`0`<br>`1` |

그림자가 시간 결계를 펼치면 N과 Q가 각각 200,000까지 늘어납니다.
