10^18까지 하나씩 나눠 볼 수는 없으니, 나머지로 크기를 확 줄이는 **유클리드 호제법**이 핵심이야.

- 호제법: `a`와 `b`의 최대공약수는 `b`와 `a % b`의 최대공약수와 같아. `b`가 0이 될 때까지 되풀이하면 남은 `a`가 답이야. 수가 아주 빨리 작아져서 10^18이어도 100번 안쪽이면 끝나.
- `math.gcd(a, b)`가 이 계산을 그대로 해 줘. JS에는 내장 gcd가 없어서 직접 썼던 함수지.
- 최소공배수는 `a * b // g`. 두 수가 함께 가진 몫 `g`가 곱에 두 번 들어 있으니 한 번 나눠 주는 거야. `a * b`만 쓰면 공배수이긴 해도 가장 작은 게 아니야.
- `/`는 결과가 실수(float)라서 10^36 같은 수는 `1e+36`처럼 끝자리가 뭉개져. 나누어떨어지는 걸 알 때는 `//`.
- 호제법을 직접 쓸 때는 `a, b = b, a % b`가 원래 `a`, `b`를 덮어써. 반복이 끝나면 `b`는 0이라서, 최소공배수에는 반복 전에 남겨 둔 원래 값을 써야 해.
- Python 3.9부터는 `math.lcm(a, b)`도 있어. 실전 환경의 Python 버전을 모를 때는 `a * b // math.gcd(a, b)`가 안전해.
