소수 판정을 **아주 많이** 해야 할 때는 하나씩 나눠 보지 말고, 소수 표를 한 번 만들어 두고 읽기만 하는 게 핵심이야.

- 짝 `(p, q)`에서 `p ≤ q`이니까 `p`는 2부터 `n // 2`까지만 보면 되고, `q`는 `n - p`로 정해져. `range(2, n // 2 + 1)`처럼 끝에 `+ 1`을 붙여야 `5 + 5` 같은 같은 소수 짝도 들어가.
- `p`마다 `p`와 `n - p`를 √까지 나눠 보면, n이 200만일 때 판정을 수십만 번 해서 시간 안에 못 끝나.
- **에라토스테네스의 체**: `is_prime = [True] * (n + 1)`에서 0과 1을 지우고, 아직 `True`로 남은 `i`마다 `i * i`, `i * i + i`, … 를 `False`로 지워. `i * i`부터 시작하는 건 그보다 작은 배수(`2 * i`, `3 * i`, …)는 더 작은 소수가 이미 지웠기 때문이야. 바깥 반복은 `i * i <= n`까지면 충분해.
- 표를 다 만들면 판정은 `is_prime[p] and is_prime[n - p]`로 칸 두 개를 읽는 것뿐이야. 체를 만드는 일은 대략 n × (아주 작은 수)번이라 200만이어도 금방 끝나.
- `range(2, n - 1)`처럼 끝까지 훑으면 `5 + 7`과 `7 + 5`를 둘 다 세서 답이 거의 두 배가 돼.
