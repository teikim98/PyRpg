글자를 0~25 칸 번호로 바꾸고, n을 더하고, `% 26`으로 한 바퀴 돌린 다음 다시 글자로 바꾸면 돼.

- 소문자: `chr((ord(c) - ord("a") + n) % 26 + ord("a"))`
- 대문자: 기준만 `ord("A")`로 바꿔서 `chr((ord(c) - ord("A") + n) % 26 + ord("A"))`
- 공백은 `if c == " "`로 걸러서 그대로 붙여.
- `chr(ord(c) + n)`만 하면 `z`를 넘어갈 때 `{`, `|` 같은 기호가 나와. 0~25로 바꾼 뒤 `% 26`을 해야 `z` 다음이 `a`가 돼.
- 대문자에 `ord(c) - ord("a")`를 쓰면 `ord("A") - 97 = -32`처럼 음수 칸이 나오고, 다시 `ord("a")`를 더하니까 결과가 소문자가 돼 버려. 대문자는 `isupper()`로 골라서 `A` 기준으로 계산해.
- 결과는 빈 문자열 `answer = ""`에 한 글자씩 `+=`로 붙여도 되고, 리스트에 모아서 `"".join`해도 돼.
