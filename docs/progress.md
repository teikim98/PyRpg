리서치에서 접근이 막혀 확인하지 못한 것들입니다. 설계를 막지는 않지만, 해당 작업을 할 때 확인합니다.

| 항목 | 확인할 때 | 방법 |
|---|---|---|
| 프로그래머스 Python 버전 | 실전 추천 안내 문구를 쓸 때 | 접속 가능한 환경에서 `import sys; print(sys.version)` 제출 |

| solved.ac 티어(2025-06-29 이후 변동, 일부 미확인) | Phase 3 지역 추가 시 | solved.ac API |
| Kenney 에셋 라이선스 원문 | Phase 2 단위 8(도트 아트) | 내려받은 묶음의 `License.txt` |
| 실제 OS 한글 입력기에서 CodeMirror 입력 | Phase 2 단위 6 | Windows·macOS에서 직접 입력 |
| Firefox·Safari의 재귀 한계와 SharedArrayBuffer | Phase 2 단위 3 이후 | 해당 브라우저에서 콘텐츠 스모크 테스트 |
