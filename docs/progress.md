- Python 응시 주의점: 프로그래머스 Python 버전, 재귀 한도, 입출력 속도, 시간 초과·메모리 초과의 흔한 원인. 백준 언어별 정책은 서비스 종료로 원문을 볼 수 없으므로 간접 자료로 확인합니다.

## 6. 정해 둔 방향과 초안 아이디어(design.md에 아직 반영하지 않음)

- **큰 정수 처리(§11에 반영 예정)**: 함수 구현형 테스트에 10^18 같은 값이 들어가는데, 이를 JSON 숫자로 저장하면 JS의 `JSON.parse` 단계에서 값이 손상됩니다. 그래서 인자와 기댓값을 Python 리터럴 문자열로 저장하고, Pyodide 안에서 `ast.literal_eval`로 파싱한 뒤 Python의 `==`로 비교하는 방식을 쓸 계획입니다.
  - 주의: `10**18` 같은 식은 `ast.literal_eval`이 거부하므로, 데이터에는 숫자를 풀어서 적습니다.
  - Pyodide가 JS와 Python 사이에서 큰 정수를 어떻게 변환하는지는 아직 미확인입니다(③ 기술 조사).
- **Pyodide 버전**: 0.29.5(Python 3.13.2)와 314.0.7(Python 3.14.2) 가운데 고릅니다. 로컬 검증 환경과 minor 버전이 같고 안정성을 우선하는 원칙에 맞는 0.29 라인이 유력합니다. 다만 0.29 라인의 지원 종료 시점을 확인한 뒤에 결정합니다.
- **백준 종료 대응**: 문제 데이터에는 백준 번호만 저장하고 URL은 설정값과 조합합니다. 재개 전까지는 프로그래머스 문제 비중을 높이는 방안을 검토합니다. 실전 추천 문제를 어떻게 안내할지는 사용자에게 확인해야 합니다.
- **커리큘럼 수정 후보(근거 약함, ② 조사 후 확정)**: 기초 종합(구현·시뮬레이션) 지역이나 보스 추가, 정수론 기초(소수 판정, 에라토스테네스의 체, GCD) 추가, 그리디를 그래프보다 앞으로 이동
- **지역 이름 초안(미확정)**: §2.2의 이야기 흐름에 맞춘 이름입니다.
