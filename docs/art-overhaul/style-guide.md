## 3. 그리는 규칙

### 3.1 외곽선

- **바깥 외곽선만**, 1px, 상하좌우로 닿는 칸(대각선 아님). 순검정(`000000`)과 `ffffff`는 쓰지 않습니다.
- 외곽선 색 = 닿은 재질 램프의 `ol`. 여러 재질에 닿으면 그중 가장 어두운 `ol`. `cozypal.auto_outline(grid)`가 이 규칙대로 칠합니다.
- 안쪽 경계(팔과 몸통, 턱과 옷깃, 판자 이음새)는 외곽선 대신 **그늘색 1px** 또는 그 재질의 `ol`로 나눕니다.
- 타일(바닥)은 외곽선을 두르지 않고, 이음새·줄눈만 그 재질의 `ol`로 씁니다. 바닥 위에 서는 물체(덤불·상자·우물)는 외곽선을 두릅니다.

### 3.2 음영(3단 + 강조)

- 빛은 **왼쪽 위**에서 옵니다. 덩어리마다 왼쪽·위 가장자리 1px = `hi`, 오른쪽·아래 1px = `shade`, 안쪽 = `base`.
- `spec`은 덩어리 하나에 1~3픽셀(젖은 잎 끝, 금속 반짝임, 물결 끝). 넓게 칠하지 않습니다.
- 그라데이션·디더링 금지. 디더링은 질감 점(§3.3)에서만.
- 그림자가 땅에 닿는 곳(덤불 아래, 벽 아래 첫 줄)은 땅 재질의 `shade` 1~2px.

### 3.3 질감 점(낡았지만 아늑하게)

`cozypal.speckle(grid, from, to, density, seed)`로 찍습니다. 점끼리 상하좌우로 붙지 않고, 좌표 해시라 결정적이며 타일을 이어 붙여도 같습니다.

| 재질 | 점 | 밀도 |
|---|---|---|
| 흙길(sand) | `shade` 닳은 자국 + `hi` 모래알, 조약돌 2개(밝음 2px + 그늘 2px) | 7% + 4% |
| 판석(stone) | `shade` 얼룩 + 틈에 낀 `moss.base` | 8% + 2.5% |
| 나무 판자(wood) | `shade` 결 + 판자마다 옹이 1개(`ol`) + 못(`cream.hi`) | 6% |
| 크림 금속판(cream) | `shade` 얼룩 + 리벳 아래 녹 물때(위 `rust.hi` 1px, 아래로 `cream.shade` 건너뛰며 2~4px) | 5% |
| 빨간 널(brick) | `shade` 얼룩 + 바랜 흰 점(`cream.hi`) | 10% + 3% |
| 풀(grass) | 4×4 칸마다 많아야 한 송이: 'ㅅ'자 송이 30%, 외잎 20%, 그늘 점 12%(§4.1) | |

질감 점은 **기본색 위에만** 찍습니다(밝음·그늘 가장자리에 찍으면 형태가 무너집니다).

### 3.4 채도·명도 배분

- 바닥(풀·길·판석)은 중간 명도. 벽·지붕은 바닥보다 한 단계 어둡거나 밝게 해서 높이를 구분합니다.
- **주인공 일행이 가장 눈에 띄어야** 합니다: 캐릭터 옷의 `hi`가 그 자리 바닥 `base`보다 밝게. NPC는 주인공보다 채도를 한 단계 낮춘 옷(보라·초록·빨강 램프)을 씁니다.
- 채도 높은 색(lamp·flower·blue·teal의 hi/spec)은 2×2픽셀 이하의 점·장식으로만.

### 3.5 반짝임

- 노란 4방향 별: 가운데 `sparkle` 1px + 상하좌우 `sparkle2` 1px(3×3). 엔진 입자도 이 모양·색을 씁니다.
- 아트 안에 넣는 반짝임(보물·룬·물)은 타일 하나에 1개 이하.

## 4. 타일 규칙(16×16 유지)

기준 구현은 [`tools/art/cozysamples.py`](../../tools/art/cozysamples.py)이고 결과는 `materials.png`에 있습니다.

### 4.1 바닥

- 가장자리가 이어져야 합니다(무늬는 `x % 16`, `y % 16` 기준). 3×3 이어 붙임에서 이음새·반복 줄무늬가 보이면 안 됩니다.
- 풀(`grass`): `base` 바탕, 4×4 칸마다 해시로 송이 하나('ㅅ'자 `hi` 2px + 가운데 아래 `shade` 1px, 25% 확률로 위에 `spec` 1px), 또는 외잎(`hi` 1 + `shade` 1), 또는 그늘 점.
- 꽃 변형(`grass_flower`): 풀 위에 꽃 2~3송이, 꽃은 십자 4px `hi` + 가운데 `lamp.hi` + 오른쪽 아래 `shade` 1px.
- 물(`water`): `base` 바탕, 물결 줄 6개(밝음 2~3px, 바로 아래 그늘 같은 길이), 강조 반짝임 1px. **애니메이션 3프레임**: 프레임마다 물결을 오른쪽으로 2px 옮기고 반짝임 자리를 바꿉니다. fps 3 권장.

### 4.2 풀 덤불 경계(레퍼런스의 넘어오는 풀)

- 풀과 길·광장이 만나는 경계 타일은 **풀이 길 쪽으로 1~3px 늘어집니다.** 2픽셀 폭 잎 덩어리마다 깊이를 해시로 1~3px, 맨 아래 픽셀은 `grass.shade`, 그 아래 1px은 `grass.ol`(잎 그림자). 짝수 열의 절반은 잎 끝이 1px 더 늘어집니다(`cozysamples.grass_edge_over_path`).
- **구현(결정 20, 2026-10-19)**: 타일 한 칸은 이웃을 모르므로 경계는 타일 그림이 아니라 **엔진이 맵을 그릴 때 얹는 경계 장식 조각**으로 그립니다. 맵 데이터·충돌은 그대로이고 지역 1~6에 한 번에 적용됩니다.
  - 조각: [`tools/art/edge_tiles.py`](../../tools/art/edge_tiles.py) → `assets/tiles/edges.png`(16×16, 배경 투명, 52조각). 이름은 `<묶음>_<방향>`이고 방향은 넘어오는 이웃 쪽(n·s·w·e, 대각선 nw·ne·sw·se는 양옆 두 칸이 넘어오지 않는 안쪽 모서리만).
  - 풀 덤불 묶음 `grass`·`forest`·`island`·`mist`: 그 지역 풀 타일의 질감을 이어 그린 잎이 위·왼쪽에서 1~3px 늘어지고(끝은 그늘, 아래·오른쪽에 잎 그림자 선), 아래쪽 풀은 잎 끝이 1~2px 솟습니다. 위 규칙(2픽셀 폭 덩어리마다 깊이 해시)을 그대로 씁니다.
  - 물가 `shore`(반투명이라 지역마다 다른 물 색에 그대로 얹힘): 위쪽 땅은 둑 그늘 2px + 물거품 선, 나머지 방향은 끊긴 물거품 선 + 폭이 들쭉날쭉한 얕은 물. 어두운 물(동굴 웅덩이·호수, 분류 `water_dark`)은 흰 물거품이 밝은 네모 테두리로 읽혀서 `shore_dark`를 씁니다: 짙은 둑 그늘 2px(위쪽 땅만)과, 가장자리에서 1px 안쪽에 물빛에 가까운 옅은 잔물결 조각(1~2px)을 드문드문 둡니다(이어진 선 없음). 물 위 구조물(부두·다리·갑판)은 `deck` 그늘(위 3px·왼쪽 2px), 벽·지붕 바로 아래 칸은 `wall` 발치 그늘 2px(§3.2 '벽 아래 첫 줄').
  - 분류와 규칙: manifest `edgeDecor.terrain`(타일 → grass·forest·island·mist·ground·deck·water·water_dark·wall)과 `rules`(그리는 순서: 벽 그늘 → 물가(밝은 물·어두운 물) → 갑판 그늘 → 풀 덤불). 새 물 타일은 바탕 밝기로 water / water_dark를 고릅니다. 새 지역 타일은 terrain에 분류만 넣으면 됩니다. 새 풀 색이 필요하면 `edge_tiles.GRASS_SETS`에 묶음을 더합니다.
  - 엔진: [`src/game/edgeDecor.ts`](../../src/game/edgeDecor.ts)(순수 함수, 단위 테스트 `tests/unit/game-edges.test.ts`)가 ground 레이어의 이웃 분류로 조각을 고르고, `WorldScene`이 바닥 위·물체 아래(깊이 0.5) 레이어로 그립니다.
  - 전후 비교: [`edges-before-after.png`](edges-before-after.png)(`python tools/art/edge_compare.py`, 원본 화면은 `screens/edges-rNN-*.png`, `tests/e2e/edges.spec.ts`가 찍음).

### 4.3 물체(덤불·나무·상자·우물·가로등)

- 풀이나 바닥을 배경으로 깐 한 칸 타일. 물체에는 외곽선(§3.1), 발치에 땅 `shade` 그림자 1~2px.
- 잎 덩어리는 큼직하게: 원 2~3개(반지름 4px 안팎)를 겹쳐 실루엣을 만들고, 왼쪽 위 가장자리 `hi`, 오른쪽 아래 `shade`, 아래쪽 바깥 가장자리는 `leaf.shade`로 한 단계 더 어둡게. `spec` 점 2~3개.
- 여러 칸짜리 물체(집·시계탑)에 디테일을 몰아 줍니다(창문 반사 `sky`, 문패, 화분, 녹 물때).

## 5. 캐릭터(16×24, 6열 × 4행)

기준 구현: [`tools/art/charrig.py`](../../tools/art/charrig.py)(리그)와 [`tools/art/characters.py`](../../tools/art/characters.py)(주인공·누리·지역 1 NPC).

### 5.1 비율과 배치(서기 기준, 행 번호는 0부터)

| 부분 | 행 | 크기 |
|---|---|---|
| 여백(바보털·포니테일 끝) | 0~1 | |
| 머리(외곽선 포함) | 1~11 | 약 11~12px, 폭 12px 채움 + 외곽선 = 14px |
| 몸통·팔 | 12~18 | 몸통 폭 8px(4~11열), 팔은 3열·12열 1px |
| 다리·신발 | 19~22 | 다리 2px 두 개, 사이 2px |
| 발 아래 외곽선 = 땅에 닿는 줄 | 23 | |

- 프레임 아래쪽 16px이 캐릭터가 선 타일 칸에 맞는다고 보고 그립니다(발 아래 외곽선 23행 = 칸의 맨 아래 줄). 그래서 머리 위 8px은 위 칸으로 올라옵니다.
- 머리 : 몸 ≈ 11 : 12(2~2.5등신). 머리를 몸보다 넓게.

### 5.2 얼굴

- **눈은 점 2개**: 1×2px, 아래 보기에서 5열·10열(가운데 4px 띄움), 8~9행. 옆 보기는 앞쪽 하나(11열).
- 볼터치 `blush` 1px: 눈 바로 아래 줄, 눈보다 1px 바깥쪽(4열·11열).
- 입은 기본으로 그리지 않습니다(콧수염 같은 특징만).
- 앞머리가 이마를 덮고(5~7행), 옆머리 1px이 얼굴 양옆을 감쌉니다.
- 누리처럼 눈 색이 있으면 위 픽셀 `eye`, 아래 픽셀 `eye_green`.

### 5.3 옷과 색

- 주인공·누리는 밝은 옷 면적을 크게(크림 셔츠 `cloth_white`), 망토는 짧은 어깨 망토(케이프렛) 2~3행 + 아래 1행 그늘로 끝냅니다. 큰 단색 덩어리를 만들지 않습니다.
- 소매(팔)는 몸통과 다른 색이나 다른 단계로 칠해 몸통에서 떨어져 보이게 합니다.
- 벨트·끈 같은 가로선 1px이 실루엣에 리듬을 줍니다.

### 5.4 범례와 리그

손으로 쓰는 그리드는 공통 범례 문자로 씁니다(`charrig.LETTERS`): `s S z` 피부, `p` 볼터치, `e w` 눈, `a A q Q` 머리, `t T y` 윗옷, `c C x` 겉옷, `r R u` / `g G k` 장식, `b B n` 바지, `f F v` 신발. 캐릭터마다 범례 → 코지 색 이름을 정합니다(`PLAYER_LEGEND` 등).
머리 그리드(0행부터)와 몸통 그리드(12행부터 7행)를 아래·오른쪽·위 세 방향만 그리면, 왼쪽은 좌우 반전이고 팔·다리·걷기·숨쉬기·깜빡임은 리그가 만듭니다. 외곽선은 그리지 않습니다(자동).

## 6. 애니메이션

### 6.1 캐릭터 걷기 4프레임 + 대기 2프레임

열: 0 서기, 1 왼발(stepA), 2 서기, 3 오른발(stepB), 4 숨쉬기, 5 눈 깜빡임. 행: 아래·왼쪽·오른쪽·위.

| 열 | 다리 | 팔 | 몸 |
|---|---|---|---|
| 0·2 서기 | 두 다리 곧게(옆: 겹침) | 몸통 옆에 곧게, 소매 3px + 손 1px(손은 16~17행, 케이프렛이 있으면 17행) | 기준 |
| 1 왼발 | 아래·위: 화면 왼쪽 발이 1px 들림(신발이 20~21행). 옆: 가까운 다리 앞으로, 먼 다리 뒤로(그늘색), 앞뒤 발 간격 5~6px | 아래·위: 들린 발 반대쪽 팔이 1px 내려오고(앞으로) 같은 쪽 팔은 1px 올라감. 옆: 가까운 팔이 뒤로(손이 2px 뒤) | **윗몸(머리·몸통·팔) 1px 아래로** |
| 3 오른발 | 1의 좌우 반전(옆: 먼 다리 앞으로) | 1의 반대(옆: 팔이 앞으로) | 윗몸 1px 아래로 |
| 4 숨쉬기 | 서기와 같음 | 서기와 같음 | **머리만** 1px 아래로 |
| 5 깜빡임 | 서기와 같음 | 서기와 같음 | 눈 점의 위 픽셀을 피부로, 아래 픽셀을 바깥쪽으로 1px 늘린 가로선(옆: 앞쪽으로). 위 보기는 서기와 같음 |

- 엔진 재생(plan.md §3): 걸음 사이에 끊지 않고 0→1→2→3을 이어서, 한 걸음(한 칸)에 2프레임. 누리는 반 박자(1프레임) 어긋나게. 멈추면 0, 잠시 뒤 4와 0을 천천히 오가고 가끔 5.
- 새 NPC도 이 리그를 그대로 씁니다(지역 2~6은 확장 단계에서 옮김).

### 6.2 몬스터 4프레임 제자리(16×16)

- 프레임 = [기본, 눌림, 기본, 늘어남] 또는 [기본, 위로 1px, 위로 2px, 위로 1px]처럼 **한 주기가 4프레임에 돌아오는** 움직임. fps는 엔진이 정합니다(4 안팎).
- 통통 튀는 몸(슬라임 등): 1번 프레임은 폭 +2px·높이 −1px(눌림), 3번 프레임은 폭 −2px·높이 +1px(늘어남). 바닥 줄(15행)은 고정해서 발이 땅에서 떨어지지 않게.
- 나는 몸(박쥐·유령): 몸 전체가 0→−1→−2→−1px 위아래로, 날개는 1·3번에서 위로 접힘. 그림자는 그리지 않습니다(엔진).
- 눈·표정은 4프레임 내내 같은 자리(몸과 함께 움직일 때만 같이 이동). 깜빡임이 필요하면 4번째 프레임에서만.
- 외곽선·음영·질감은 §3 그대로. 지역 1 몬스터의 기존 디자인(모양·색 아이디어)은 유지하고 코지 램프로 다시 칠합니다.
- obj_chest·obj_door는 [닫힘, 열림] 2프레임 그대로. 나머지 오브젝트(obj_rune, obj_campfire, obj_sign …)는 2 또는 4프레임.

### 6.3 보스 4프레임(32×32)

- 몬스터와 같은 규칙을 2배 크기로: 숨쉬는 몸 1px, 눈·입 같은 특징부 1~2px 움직임, 4번째 프레임에 위협 동작 하나(입 벌림·눈 빛남).
- 외곽선은 1px 그대로(2px로 두껍게 하지 않음). 질감 점 밀도는 §3.3과 같게.

### 6.4 타일 애니메이션

- 프레임 타일은 타일셋 **끝에 추가**하고 이름은 `<타일>_a1`, `<타일>_a2` …. manifest:
  `"tileAnimations": { "water": { "frames": ["water", "water_a1", "water_a2"], "fps": 3 } }`
- `tools/art/check.py`가 검사합니다: 키·프레임 타일이 타일셋에 있는가, 프레임 2개 이상, 첫 프레임 = 키, fps 양수, 프레임 타일이 키보다 뒤에 있는가, 바닥 타일이면 프레임도 불투명한가.
- 움직임은 작게: 물결 2px 이동, 꽃 1px 흔들림, 불꽃 1~2px. 프레임 사이에 실루엣이 크게 바뀌면 깜빡여 보입니다.

## 7. 초상화(64×64, 누리 5종)

- 같은 팔레트의 램프를 씁니다: 머리카락 `hair_ginger`, 피부 `skin`, 망토 `cloth_olive`, 셔츠 `cloth_white`, 고글·나침반 `brass`, 리본·렌즈 `teal`, 눈 `eye_green` 계열(필요하면 `cozypal.RAMPS` 끝에 `eye_green` 램프를 추가).
- 외곽선은 재질 `ol`(§3.1), 음영 3단 + 강조(§3.2). 지금 초상화의 5~7단 램프와 그라데이션 느낌을 **3단 + 강조로 줄여** 평평하게 합니다.
- 눈은 걷기 시트보다 크게 그리되(초상화 비율), 반사광은 `eye_shine` 1~2px, 볼터치 `blush`. 배경은 투명 또는 대화창이 깔아 줍니다.
- 표정마다 바뀌는 곳은 눈·눈썹·입·홍조·효과뿐(design.md §3 공통). 디자인 특징(하이 포니테일+청록 리본, 바보털, 황동 고글, 나침반 머리핀, 초록 눈, 올리브 망토, 지도통)은 유지.
